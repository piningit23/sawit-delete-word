One word, erased forever: **delete**. If the dictionary loses the word "delete", nothing can ever be deleted again — including the word itself. A tiny Python program that writes that one word to `/output/entry.txt` for make.fun's "The Word You'd Delete From the Dictionary" bounty.

## Run it

```sh
python3 main.py
```
